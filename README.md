# 안토리아 RP 소개 사이트

- `dist/index.html`: 세계관 및 메인 표지
- `dist/characters.html`: 필레온·엘리라
- `dist/cast.html`: 조연과 정령
- `dist/gallery.html`: 공개 수록 이미지
- `dist/archive.html`: 비밀번호로 여는 언세이프 수록 이미지

이미지는 `https://gbe88.uk/KQ/`에서 직접 불러옵니다. 공개 화보는 필레온·엘리라 1–11 및 조연 21–22, 별관은 필레온·엘리라 12–20을 표시합니다.

## 배포

Vercel에서 이 저장소를 불러오면 `vercel.json`이 정적 출력 폴더 `dist`를 지정합니다. 별도 빌드 명령은 필요하지 않습니다.

별관 비밀번호는 화면에 평문으로 보이는 입력창을 사용하며, 브라우저에서는 SHA-256 해시로 비교합니다. 정적 사이트의 클라이언트 잠금이므로 강한 접근 통제 용도는 아닙니다.

## 언어

로고 오른쪽에서 한국어·English·日本語를 선택할 수 있습니다. 선택은 브라우저에 저장되어 다음 페이지에서도 유지됩니다. `dist/translations.js`에는 본문, 메타데이터, 접근성 설명, 마도코어 예시의 번역이 들어 있으며 `dist/i18n.js`가 전환을 처리합니다. 명령어도 언어별로 표시됩니다.

홈 커버는 `https://gbe88.uk/2/KQ/p.webp`의 자체 애니메이션을 사용합니다. 이미지에 포함된 글자는 원본 이미지의 일부이므로 언어 전환 대상에서 제외됩니다.

검증: `node tests/i18n.test.cjs`
